# ✈️ Flight Management System

A **C++ console-based Flight Management System** developed as a first-semester programming project. It allows users to view flights, book seats, manage bookings, and calculate fares, while providing an admin portal for flight management.

## 🚀 Features

* ✈️ View available flights
* 🎫 Book and cancel flights
* 💺 Business & Economy seat selection
* 💰 Automatic fare, tax & discount calculation
* 📅 Flight date validation
* 👤 Passenger information management
* 🔐 Admin portal for managing flights
* 💾 File handling for storing flights and bookings
